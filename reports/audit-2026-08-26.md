## Executive Summary

Both builds pass cleanly. The critical blockers this month are **dependency security vulnerabilities** in both repos — particularly a CSRF bypass in `react-router` (neo-control) that has a patch available now. neo-control's lint gate is also failing on a `setState-in-effect` anti-pattern. Component size violations persist across both repos (`AdminPage.tsx` at 1508 lines, `GameCanvas.tsx` at 3276 lines, `MoversBudget.svelte` at 1052 lines) and are the primary technical debt to address in the next sprint.

### 🟡 Medium

**CODE QUALITY**

`QUALITY [severity: medium]: neo-control/src/pages/AdminPage.tsx:88,193,198,203,208,229,238,279,311` — Multiple inline `style={{...}}` objects with raw values (fontFamily, fontSize, letterSpacing, color). These belong in `index.css` using CSS custom properties. — Move to `src/index.css` under `.admin-*` selectors; use `var(--muted)`, `var(--green)`, `var(--amber)`, `var(--pink)` already in the stylesheet.

`QUALITY [severity: medium]: neo-control/src/game/GameCanvas.tsx` — Pervasive magic numbers throughout the game loop: `435`, `560` (canvas size — constants at top, OK), `150`, `60`, `30` (damage tiers), `270` (max rock speed cap), `1254`/`1255`/`1256` (sentinel "never" timer values set to `999`), `200`/`300` (point values), `190` (impulse scalar), and others. — Group game constants in `src/game/constants.ts` with descriptive names: `DAMAGE_TIER_2`, `MAX_ROCK_SPEED`, `TIMER_INACTIVE`, `POINT_VALUE_ROCK`, etc.

**ANTI-PATTERNS**

`ANTI-PATTERN: neo-control/src/pages/AdminPage.tsx:1172–1174` — `useEffect(() => { if (authed) load(); }, [authed])` — calling an async data-fetcher directly inside an effect body. This is the pattern flagged by the lint rule `react-hooks/set-state-in-effect`. — Restructure: `if (authed) load()` should fire from the auth-completion callback (in the first `useEffect`'s `.then()`), not in a dependent effect. Alternatively, move the `authed` check into the `load` function itself and call it once from a combined effect.

`ANTI-PATTERN: where-it-counts/src/lib/components/viz/SurplusMapViz.svelte:320` — `boot().catch(console.error)` — leaving `console.error` in production code. — Replace with a proper error state: `boot().catch(err => { mapError = err.message; })` and render a fallback UI when `mapError` is set.

## 5. Top 5 Action Items

1. **[SECURITY, neo-control] Update `react-router-dom` to 7.18.2 immediately.** A CSRF bypass vulnerability (GHSA-qwww-vcr4-c8h2) affects versions `>=7.12.0 <7.18.2`. The patch is a single `npm i react-router-dom@7.18.2` and `npm audit fix` in neo-control. Do this before the next deploy.

2. **[LINT, neo-control] Fix `setState-in-effect` in `AdminPage.tsx:1172–1174`.** The lint gate is currently failing on CI. Combine the two auth `useEffect` calls or move `load()` into the `.then()` callback of the session check. This unblocks clean CI runs.

3. **[QUALITY, neo-control] Split `GameCanvas.tsx` (3276 lines).** Extract `src/game/physics.ts` (collision, velocity, mass), `src/game/draw.ts` (all canvas draw calls), and `src/game/constants.ts` (magic numbers). The component stays as the coordinator. This is the highest-leverage refactor for maintainability.

4. **[QUALITY, neo-control + where-it-counts] Split god-components `AdminPage.tsx` and `MoversBudget.svelte`.** Both are over 1000 lines. `AdminPage` splits into Auth/Charts/Filters. `MoversBudget` splits out `AllocationCard.svelte` and `MobileECSummary.svelte`.

5. **[DEPENDENCIES, neo-control] Plan TypeScript 7 upgrade.** `typescript@6.0.3` is one major version behind (7.0.2 is current). This requires reviewing breaking changes and updating `tsconfig` settings. Pair with the ESLint 10 upgrade (also one major behind) since both affect the build pipeline together.
