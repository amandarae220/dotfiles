# Monthly Audit — 2026-07-30 (habitTracker, d3examples)

## Executive Summary

**habitTracker** is a small vanilla JS task tracker with no build tooling. It has two runtime-breaking bugs — a broken CSS path and an undefined function reference — along with critical accessibility gaps: missing `lang` attribute and unlabeled dynamic form controls. No secrets or dependency exposure.

**d3examples** is a static D3.js visualization showcase with the most significant issues of this audit cycle. A security-critical HTTP (non-HTTPS) script load in `ireland.html` is the top priority. All CDN dependencies lack SRI hashes. D3 versions range from v2 to v4 across files; current is v7 — multiple major versions behind. Every chart SVG is inaccessible to screen readers. One page (`ireland.html`) is completely orphaned from navigation.

Neither repo has a `package.json`, so npm install/build/lint and `npm outdated` do not apply.

## 1. Skill Compliance

### 🚨 Critical

**SECURITY [severity: critical]: d3examples/ireland.html:947 — D3.js loaded via plain HTTP, not HTTPS — Change to `https://d3js.org/d3.v2.js` or self-host**

```html
<!-- current (unsafe) -->
<script type="text/javascript" src="http://d3js.org/d3.v2.js"></script>
<!-- fix -->
<script type="text/javascript" src="https://d3js.org/d3.v2.js"></script>
```

This is a man-in-the-middle risk: any network between user and CDN can inject arbitrary JavaScript. All other d3examples files use HTTPS or local scripts; only `ireland.html` is affected.

**A11Y [severity: critical]: habitTracker/index.html:2 — `<html>` missing `lang` attribute — Add `lang="en"`**

Screen readers cannot determine the document language, affecting pronunciation, braille translation, and language-detection tools.

**A11Y [severity: critical]: habitTracker/list.js:21–35 — Dynamically created `<label>` has no `for` attribute; checkbox has no `id` — Generate unique IDs per task and wire `label[for]` to `checkbox[id]`**

```js
// fix: generate a unique id per task
const taskId = `task-${Date.now()}`;
checkBox.id = taskId;
label.setAttribute('for', taskId);
```

Without this, screen readers cannot associate the checkbox with its label. Clicking the label text does not toggle the checkbox for keyboard/pointer users relying on label hit-area.

**A11Y [severity: critical]: d3examples — All SVG charts have no `role`, `aria-label`, or `<title>` — Screen readers cannot announce any chart content**

Affects: `barChart.html`, `bubbleChart.html`, `force.html`, `pieChart.html`, `svg.html`, `index.html`, `globe.html`. Each D3-appended `<svg>` should receive `role="img"` and `aria-label` (e.g. `aria-label="Bar chart of dataset values"`), and a `<title>` as the first child element.

```js
var svg = d3.select("#draw_here")
    .append("svg")
    .attr("role", "img")
    .attr("aria-label", "Bar chart showing dataset values on a logarithmic scale")
    .attr("width", w)
    .attr("height", h);
svg.append("title").text("Bar chart showing dataset values on a logarithmic scale");
```

### 🔴 High

**QUALITY [severity: high]: habitTracker/list.js:133 — `ajaxRequest` is referenced but never defined anywhere — Remove dead event listener**

```js
// current (broken)
addButton.addEventListener("click", ajaxRequest);
```

This throws `Uncaught ReferenceError: ajaxRequest is not defined` in the browser console on every page load. The function does not exist in `list.js` or any other file in the repo. Either implement it or delete this line.

**SECURITY [severity: medium→high]: d3examples — No SRI hashes on any CDN `<link>` or `<script>` tags — Add `integrity` and `crossorigin="anonymous"` to all CDN resources**

All d3examples pages load Bootstrap 3.3.6 from `maxcdn.bootstrapcdn.com` without integrity checks. `globe.html` additionally loads D3 from `cdnjs.cloudflare.com` without SRI. A compromised CDN can inject malicious code with no detection. Example fix for Bootstrap:

```html
<link rel="stylesheet"
  href="https://maxcdn.bootstrapcdn.com/bootstrap/3.3.6/css/bootstrap.min.css"
  integrity="sha384-1q8mTJOASx8j1Au+a5WDVnPi2lkFfwwEAa8hDDdjZlpLegxhjVME1fgjWPGmkzs7"
  crossorigin="anonymous">
```

**ANTI-PATTERN: habitTracker/list.js:133 — `addButton.addEventListener("click", ajaxRequest)` — `ajaxRequest` is undefined; this is dead broken code — Remove the line**

**QUALITY [severity: high]: d3examples — D3 library versions across files range from v2 to v4; D3 current is v7.9.0 — Standardize on v7 or at minimum v5**

| File | D3 Version | Current | Versions Behind |
|------|-----------|---------|-----------------|
| `ireland.html` | v2 | v7.9 | **5 major** 🔴 |
| `barChart.html`, `bubbleChart.html`, `force.html`, `index.html`, `pieChart.html`, `svg.html` | v3 | v7.9 | **4 major** 🔴 |
| `globe.html` | v4.2.2 | v7.9 | **3 major** 🔴 |

`d3.svg.axis()`, `d3.layout.pie()`, `d3.scale.log()`, `d3.geo.albers()` and similar APIs were removed in D3 v5+. These pages likely only run correctly in older browsers or frozen environments. v7 migration guide: https://github.com/d3/d3/blob/main/CHANGES.md

Affects `barChart.html:22`, `bubbleChart.html:182`, `force.html:394`, `globe.html:652`, `index.html:838`, `pieChart.html:975`, `svg.html:1117`. The placeholder text `"..."` is read aloud by screen readers verbatim.

Affects all pages that include the header (all except `ireland.html`).

**SECURITY [severity: medium]: d3examples/globe.html:739–764 — `.innerHTML` used to update badge values — Use `.textContent` instead**

```js
// current (unnecessary innerHTML)
document.getElementById("x_speed_badge").innerHTML = x_speed;
// fix
document.getElementById("x_speed_badge").textContent = x_speed;
```

Values are parsed with `parseFloat()` before assignment so XSS is not currently possible, but the pattern should be corrected so future edits don't accidentally introduce a sink.

**A11Y [severity: medium]: habitTracker/list.js:38 — Dynamically created edit `<input type="text">` has no accessible label — Add `aria-label="Edit task text"` on creation**

```js
editInput.setAttribute('aria-label', 'Edit task text');
```

**QUALITY [severity: medium]: d3examples — Navigation HTML is copy-pasted identically across all 8 pages — Extract to a shared JS include or use a static site generator**

Any change to the nav (adding a new chart, fixing the aria-label) requires editing 8 files. This is the root cause of the `aria-label="..."` issue persisting across all pages.

**QUALITY [severity: medium]: d3examples/globe.html:736–764 — 6 near-identical handler functions (`change_x_speed`, `change_y_speed`, `change_z_speed`, `change_x_rotation`, `change_y_rotation`, `change_z_rotation`) — Consolidate with a single parameterized function**

```js
function updateControl(axis, type) {
    const id = `${axis}_${type}`;
    window[`${axis}_${type}`] = parseFloat(document.getElementById(id).value);
    document.getElementById(`${id}_badge`).textContent = window[`${axis}_${type}`];
}
```

**QUALITY [severity: medium]: habitTracker/index.html:6 — Broken CSS path: `href="styles.css"` but file is named `style.css` — Fix href to `style.css`**

```html
<!-- current (broken) -->
<link rel="stylesheet" href="styles.css" type="text/css" media="screen" charset="utf-8">
<!-- fix -->
<link rel="stylesheet" href="style.css">
```

The page loads with no styles applied.

## 5. Top 5 Action Items

1. **[d3examples/ireland.html] Fix HTTP → HTTPS on D3 v2 script load** (5 min) — `http://d3js.org/d3.v2.js` is a MITM attack surface. Change scheme to `https://`. Highest-severity security issue in either repo.

2. **[habitTracker/list.js:133] Remove undefined `ajaxRequest` event listener** (2 min) — Throws `ReferenceError` in console on every page load, and could confuse future contributors into implementing a feature that was never spec'd. Delete the line.

3. **[habitTracker/index.html:6] Fix broken CSS path `styles.css` → `style.css`** (2 min) — The page loads completely unstyled in its current state. Trivial one-character fix.

4. **[habitTracker] Fix dynamic label/input association** (15 min) — Generate a unique `id` per task, set it on the checkbox, and add a matching `for` on the label. This is the core WCAG 2.1 AA failure in habitTracker and blocks screen reader users from using the app at all.

5. **[d3examples] Add SRI hashes to all CDN resources** (30 min) — Bootstrap 3.3.6 across 7 pages and D3 on `globe.html` are all loaded without `integrity` checks. Use SRI Hash Generator (https://www.srihash.org) to generate hashes, then add `integrity` + `crossorigin="anonymous"` to each tag. This is a supply-chain risk mitigation that takes one pass to apply everywhere.
